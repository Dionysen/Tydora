# 思维导图设置

本页配置 [[高级功能/思维导图]] 与 [[知识图谱]] 的显示参数，让你按喜好调整节点密度、连线粗细与物理布局。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，切换到「思维导图」标签。其中「关系图谱」分组对应知识图谱。

## 思维导图设置

基于 Markmap 渲染，可调参数：

### 最大宽度

设置思维导图节点的**最大宽度**，过宽的内容会换行，避免单节点横向撑爆画布。

### 间距

设置节点之间的**间距**，控制整体的疏密程度。

### 动画时长

设置展开 / 折叠节点的动画持续时间（毫秒）。调小更利落，调大更柔和。

### 线条宽度

设置连接线的粗细。

### 颜色冻结层级

设置「从第几层开始使用不同颜色」区分层级。例如设为 2，则根节点与一级节点同色，二级及以下开始用色阶区分，便于看清深度。

## 知识图谱设置

基于 D3.js 力导向图，可调参数：

### 节点大小

设置图谱节点的默认半径。链接越多的笔记在图谱中会被渲染得更大，此参数设定基准大小。

### 连线粗细

设置连线的默认粗细，频率高的链接会更粗。

### 力度

调整力导向图的**物理模拟强度**（电荷力）。值越负，节点间排斥越强，布局越松散；越接近 0，越容易聚成一团。

> [!TIP]
> 仓库链接很多时，适当增大「力度」的绝对值能让聚类更清晰；链接稀疏时减小可避免节点飞得太散。
