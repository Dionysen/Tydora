# 快捷键速查表

Tydora 内置 40+ 个键盘快捷键，下表为**默认配置**。所有快捷键都可以在 [[设置/快捷键设置]] 中查看、修改或重置为默认值。

> [!NOTE]
> 表中 `Ctrl` 在 macOS 上对应 `Cmd`（⌘）。部分组合使用 `Ctrl+Alt+数字`，在带小键盘的键盘上直接使用主键区数字即可。

## 关于快捷键冲突的说明

> [!WARNING]
> 由于历史原因，部分默认快捷键存在重叠，实际以**全局快捷键**为准：
> - `Ctrl+O` 同时被绑定到「有序列表」与「快速打开文件」。运行时**快速打开优先**，因此 `Ctrl+O` 会打开文件而非插入有序列表。若你常用有序列表快捷键，建议在 [[设置/快捷键设置]] 中为「有序列表」重新分配一个不冲突的组合。
> - `Ctrl+P` 同时被绑定到「分屏预览」与「命令面板」。运行时**命令面板优先**。
>
> 所有快捷键均可在设置中自定义，分配后即时生效。

## 自定义快捷键

1. 按 `Ctrl+,` 打开设置。
2. 切换到「快捷键」标签。
3. 在列表中找到目标命令，点击当前的快捷键组合。
4. 按下新的组合键，保存即可。

> 详见 [[设置/快捷键设置]]。
