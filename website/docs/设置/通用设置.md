# 通用设置

通用设置管理应用的**外观、字体与自动保存**等基础选项，是每次安装后最先该看一眼的地方。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，默认停在「通用」标签。

## 外观模式

设置应用的浅色 / 深色表现：

- **跟随系统** —— 自动匹配操作系统的外观设置
- **浅色** —— 强制浅色模式
- **深色** —— 强制深色模式

> 单一主题的观感会随外观模式变化；深色主题（如 Mint Dark）在「深色」下最佳。见 [[内置主题]]。

## 字体设置

### 编辑器字体

选择编辑器中使用的字体：

- 系统默认
- LXGW WenKai（霞鹜文楷，适合中文写作）
- 等宽字体（适合代码与表格对齐）
- 其他系统已安装字体

### 字号

调整编辑器正文字号，范围 **12–32 px**。拖动滑块或输入数值即可。

> [!TIP]
> 中文写作推荐霞鹜文楷 + 16–18px；代码密集场景可用等宽字体。

## 自动保存

开启后，文件在停止输入约 1 秒后**自动写入磁盘**，无需频繁按 `Ctrl+S`。

### 延迟时间

设置自动保存的等待时长（秒），避免每次击键都触发写入。默认值已兼顾及时性与性能。

> [!NOTE]
> 即使开启自动保存，`Ctrl+S` 仍可用于立即保存。

## 主题资源目录

查看与修改主题文件的存储位置。导入的 [[Typora主题]] 与自定义主题都保存在此目录，你可以直接管理其中的 CSS 文件。
