# 编辑器设置

编辑器设置管理**编辑行为、渲染选项与语法高亮**等配置，决定你写作时的细节体验。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，切换到「编辑器」标签。

## 默认编辑模式

设置新打开文件时的默认模式：

- **即时渲染（IR / WYSIWYG）** —— 所见即所得，推荐日常写作
- **源码模式（SV）** —— 纯 Markdown 文本，适合精细调整

> 任何时候都可用 `Ctrl+/` 临时切换。详见 [[02-编辑器/01-编辑模式]]。

## 打字机模式

开启后，光标始终保持在屏幕中央。也可随时用 `Ctrl+Alt+T` 开关。

> 详见 [[02-编辑器/10-打字机模式]]。

## Markdown 渲染

### 数学公式

开启 / 关闭公式渲染，并选择引擎：

- **KaTeX** —— 速度快、兼容性好（推荐）
- **MathJax** —— 功能更全

> 详见 [[02-编辑器/04-数学公式]]。

### 代码高亮

开启 / 关闭代码语法高亮，并选择高亮主题。

> 详见 [[06-主题与外观/03-代码高亮主题]] 与 [[02-编辑器/03-代码块]]。

### Mermaid 图表

开启 / 关闭 Mermaid 图表的实时渲染。

> 详见 [[02-编辑器/05-Mermaid图表]]。

### 脚注

开启 / 关闭 `[^1]` 脚注语法支持。

### 目录

开启 / 关闭 `[toc]` 目录语法。开启后，文中的 `[toc]` 会渲染为当前文档目录。

## 字数统计

开启后在编辑器某处（通常底部状态栏）显示当前文档的**字数、字符数、行数**，便于把控篇幅。

## 缓存设置

提供「清除缓存」操作，用于解决偶发的渲染异常（如样式不刷新、图表不更新）。遇到显示问题可先尝试清除缓存。

## XSS 过滤

开启后，过滤 Markdown 中可能存在的跨站脚本（XSS）代码，提升打开不可信笔记时的安全性。建议保持开启。

> [!WARNING]
> 关闭 XSS 过滤会允许笔记中的脚本执行，仅在你完全信任笔记来源时考虑关闭。
