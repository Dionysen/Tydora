# Tydora 帮助文档

欢迎来到 **Tydora 帮助文档**。

Tydora 是一款基于 Tauri v2 + React 19 构建的现代化桌面 Markdown 编辑器，集成了即时渲染（WYSIWYG）与源码双模式编辑、WikiLink 双向链接、知识图谱、思维导图、白板画布等能力，帮助你像搭建「数字花园」一样管理知识。



## 新手上路

如果你是第一次使用 Tydora，建议按下面的顺序阅读，大约 10 分钟即可上手：

1. [[开始使用/快速开始]] —— 下载安装、打开仓库、写下你的第一篇笔记
2. [[编辑器/编辑模式]] —— 理解「即时渲染」与「源码」两种编辑模式，以及随时切换
3. [[编辑器/Markdown语法]] —— 了解 Tydora 支持的完整 Markdown 与扩展语法
4. [[知识管理/Wiki链接]] —— 用 `[[Wiki链接]]` 把零散笔记连成知识网络
5. [[知识管理/知识图谱]] —— 在力导向关系图中俯瞰你的知识宇宙
6. [[高级功能/白板画布]] —— 用无限画布自由组织想法、笔记与素材
7. [[高级功能/发布网站]] —— 一键把仓库发布为可分享的静态网站
