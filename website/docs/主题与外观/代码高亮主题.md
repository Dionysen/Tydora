# 代码高亮主题

代码块的配色**独立于应用主题**，可在 11 款高亮主题中自由选择，让代码既清晰又养眼。

> [!NOTE]
> 代码高亮由 highlight.js 驱动，支持 36 种编程语言的语法着色（见 [[代码块]]）。

## 可用主题

### 浅色主题

- **Atom One Light** —— Atom 编辑器经典浅色
- **GitHub Light** —— GitHub 风格浅色
- **VS Code Light** —— VS Code 默认浅色
- **Solarized Light** —— Solarized 浅色配色

### 深色主题

- **Atom One Dark** —— Atom 编辑器经典深色
- **GitHub Dark** —— GitHub 风格深色
- **VS Code Dark** —— VS Code 默认深色
- **Nord** —— 北欧冷色调
- **Monokai** —— 经典 Monokai
- **Dracula** —— 吸血鬼风格深色
- **Solarized Dark** —— Solarized 深色配色

## 切换主题

1. 打开设置（`Ctrl+,`）。
2. 切换到「编辑器」标签。
3. 在「代码高亮主题」下拉菜单中选择。

## 自动切换

默认情况下，代码高亮主题会**跟随应用外观**自动在浅 / 深之间切换：

- 应用为浅色 → 使用浅色代码主题
- 应用为深色 → 使用深色代码主题

可在设置中关闭自动切换，固定为某一款主题。

> [!TIP]
> 若你常年在深色应用主题下写作，建议关闭自动切换并手动指定一款深色高亮主题，避免浅色代码块在暗背景下刺眼。

## 预览效果

在 [[设置/编辑器设置]] 的「代码高亮主题」处会显示所选主题的预览，方便对比后再决定。
