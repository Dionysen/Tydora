# 关于 Tydora

Tydora 是一款基于 Tauri v2 + React 19 构建的现代化桌面 Markdown 编辑器，支持 WYSIWYG 与源码双模式编辑、WikiLink 双向链接、知识图谱、思维导图、白板画布等功能。

## 版本信息

- 当前版本：0.1.1
- 构建框架：Tauri v2
- 前端框架：React 19
- 编辑器引擎：TipTap 3.x（WYSIWYG）+ CodeMirror 6（源码）

## 检查更新

1. 打开设置（`Ctrl+,`）
2. 切换到"关于"标签
3. 点击"检查更新"

Tydora 支持自动更新，启动时会自动检查是否有新版本。

## 功能特性

- 两种编辑模式：即时渲染（WYSIWYG）+ 源码模式（SV）
- 多仓库管理与文件树
- WikiLink 双向链接与反向链接面板
- 知识图谱可视化
- 思维导图
- 白板画布（React Flow 无限画布）
- Callout 提示块（15 种类型）
- Mermaid 图表渲染
- Frontmatter 属性面板
- 一键发布为静态网站
- 8 个内置主题 + 自定义主题支持
- 11 种代码高亮配色
- 40+ 可自定义快捷键
- 图片、视频、音频、PDF 预览

## 技术栈

- **后端**：Rust (Tauri v2)
- **前端**：React 19 + TypeScript + Vite 6
- **编辑器**：TipTap 3.x（WYSIWYG）+ CodeMirror 6（源码）
- **可视化**：D3.js（图谱）、markmap（思维��图）、Mermaid（图表）、React Flow（白板）
