# 发布网站

Tydora 支持将笔记仓库（Vault）发布为静态网站，让您的笔记可以在线分享。

## 发布流程

1. **配置发布设置**：设置站点名称、描述等基本信息
2. **选择发布模式**：完整发布或仅公开笔记
3. **开始发布**：一键构建静态网站
4. **预览或部署**：本地预览或上传到服务器

## 发布模式

### 完整发布

发布 Vault 中的所有 Markdown 文件。

适合个人知识库或项目文档场景。

### 仅公开笔记

仅发布 Frontmatter 中包含 `publish: public` 的文件。

适合选择性分享部分笔记的场景。

## 发布配置

| 配置项 | 说明 |
|--------|------|
| 站点名称 | 网站标题 |
| 站点描述 | 网站描述（SEO） |
| 语言 | 网站语言（中文/英文/日文/韩文） |
| 站点 URL | 最终部署的网站地址 |
| 页脚 | 自定义页脚内容 |
| 仓库目录 | Vault 中要发布的目录 |
| 构建模式 | 完整发布 / 仅公开笔记 |
| Base Path | 部署子路径（如 GitHub Pages） |
| 输出目录 | 构建产物的输出位置 |

## 预览站点

构建完成后，可以：

- **本地预览**：启动内置 HTTP 服务器，在浏览器中预览
- **打开目录**：在文件管理器中打开输出目录
- **直接部署**：将输出目录部署到任意静态托管服务

## 技术实现

- 基于 `@abstractwebunit/markdown-publish` CLI 构建
- 生成 Angular SPA 静态站点
- 支持 WikiLink 双向链接在站点中的导航
- 后处理脚本自动优化落地页

## 部署建议

构建完成的静态网站可以部署到：

| 平台 | 说明 |
|------|------|
| GitHub Pages | 免费，支持自定义域名 |
| Vercel | 一键部署，全球 CDN |
| Netlify | 支持表单和函数 |
| 自有服务器 | 任意 HTTP 服务器 |
