# 文件预览

除了 Markdown，Tydora 还支持直接预览多种图片、视频、音频与文档文件，无需离开应用就能查看素材。

## 支持的格式

### 图片

JPG、PNG、GIF、WebP、BMP、SVG、AVIF、HEIC、ICO

### 视频

MP4、WebM、OGG、MOV、AVI、MKV、WMV、FLV、M4V

### 音频

MP3、WAV、OGG、FLAC、AAC、M4A、WMA

### 文档

PDF

## 如何预览

- 在文件树中**双击**非 Markdown 文件，打开预览。
- 在 Markdown 正文中点击图片链接，也可在当前位置预览。
- 用 `![[图片.png]]` 嵌入的图片会直接显示在笔记中（见 [[03-知识管理/02-嵌入内容]]）。

## 图片预览

- 支持缩放与拖拽平移
- 显示图片尺寸信息
- 支持透明背景显示（如 PNG / WebP / SVG）

## 视频预览

- 内置播放控件（播放 / 暂停 / 进度 / 音量）
- 支持全屏播放
- 显示播放进度条

## 音频预览

- 内置播放控件
- 显示播放进度

## PDF 预览

- 内置 PDF 查看器
- 支持翻页与缩放
- 适合在笔记旁对照资料

> [!NOTE]
> 图片的存储位置与命名规则可在 [[07-设置/06-图片设置]] 中配置；粘贴 / 拖入图片的行为也由该设置控制。
