# 仓库（Vault）

Tydora 使用「仓库（Vault）」概念来管理笔记文件。**每个仓库就是一个本地文件夹**，仓库内的所有 Markdown 文件、子文件夹、图片与媒体都会被纳入文件树、链接索引与知识图谱。

> [!NOTE]
> 仓库只记录文件夹的**路径**，不会移动、复制或改动你的任何文件。你可以放心地把已有的 Markdown 文件夹直接添加为仓库。

## 添加仓库

1. 点击左侧边栏底部的**仓库切换器**（显示当前仓库名）。
2. 选择「添加仓库」。
3. 在系统文件选择器中挑选一个文件夹（也可新建空文件夹）。
4. 确认后，左侧文件树立即加载该文件夹内容。

## 切换仓库

1. 点击仓库切换器。
2. 在下拉列表中点击目标仓库。
3. 文件树与当前打开的笔记会切换到该仓库。

> [!TIP]
> 多仓库适合按项目、按主题或按公私分开放置笔记。例如：一个仓库放工作笔记，一个仓库放个人知识库。

## 移除仓库

1. 点击仓库切换器。
2. 在仓库列表中悬停目标仓库，点击出现的删除（垃圾桶）图标。
3. 确认移除。

> [!WARNING]
> 移除仓库**只是解除 Tydora 对它的引用**，不会删除磁盘上的文件夹与文件。若想彻底删除，请在文件管理器中操作。

## 多仓库管理

- 同时管理多个仓库，按场景隔离内容
- 每个仓库独立维护文件树、链接索引与最近打开记录
- 切换仓库不会影响其他仓库的数据

## 最近打开的文件

每个仓库会分别记录最近打开的文件，方便在不同仓库间快速回到上次编辑的位置。

## 文件系统监控

Tydora 会监控仓库文件夹的外部变动：当你在文件管理器里新增、重命名或删除文件时，文件树与链接索引会**自动更新**，无需手动刷新。

> [!NOTE]
> 外部修改触发的索引更新是增量的，仅处理变化的部分，不会卡顿编辑器。详见 [[知识管理/链接索引]]。
