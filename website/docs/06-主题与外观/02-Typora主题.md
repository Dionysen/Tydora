# Typora 主题

Tydora 支持导入和使用 **Typora 的 CSS 主题文件**，让你把熟悉的 Typora 视觉风格带到 Tydora 中。

> [!NOTE]
> 导入入口在设置的「主题」标签中。导入后，主题会出现在内置主题列表下方，可随时切换。

## 导入方法

1. 打开设置（`Ctrl+,`）。
2. 切换到「主题」标签。
3. 点击「导入主题」。
4. 选择 Typora 的 `.css` 主题文件。
5. 确认后，主题被加入列表并立即可用。

## 主题文件位置

导入的主题保存在 Tydora 的**主题资源目录**中（可在 [[07-设置/01-通用设置]] 查看与修改该目录）。你可以直接在该目录中管理 CSS 文件。

## 兼容性说明

Tydora 基于 TipTap 3.x + CodeMirror 6 引擎，与 Typora 的渲染引擎并不相同，因此主题效果会有差异：

### 兼容较好的部分

- 颜色方案（背景、文字、强调色）
- 字体设置
- 基础排版与布局
- 代码块样式

### 可能有差异的部分

- 复杂的 CSS 动画
- 依赖特定 DOM 结构的样式
- 某些自定义组件外观

> [!TIP]
> 若导入后某处样式不理想，可直接编辑主题资源目录中的对应 CSS 文件微调，保存后切换主题即可生效。

## 管理主题

### 查看已导入主题

在设置「主题」标签中，导入的主题会与内置主题一并列出。

### 删除主题

1. 在主题列表中悬停目标主题。
2. 点击删除（垃圾桶）图标。
3. 确认删除。

> [!WARNING]
> 删除会移除该主题文件，当前正在使用该主题的笔记会回退到默认主题。
