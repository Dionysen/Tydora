# 白板画布

Tydora 的白板画布基于 React Flow 构建，提供一个无限画布用于可视化组织你的想法、笔记和文件。

## 打开白板

1. 在文件树中右键选择"新建白板"
2. 或在命令面板（`Ctrl+P`）中搜索"白板"
3. 白板文件以 `.canvas` 扩展名保存

## 节点类型

白板支持多种节点类型，满足不同的内容组织需求：

### 文本节点

自由编辑的文本块，使用 TipTap 编辑器即时渲染。

- 支持 Markdown 语法
- 可以任意拖拽和调整大小
- 适合标注和说明

### 笔记卡片

引用 Vault 中的 Markdown 文件。

- 显示笔记标题和摘要
- 点击跳转到笔记原文
- 支持双向链接关联

### 文件引用

引用图片、视频、音频、PDF 等媒体文件。

- 图片直接显示缩略图
- 视频和音频文件显示图标
- PDF 显示文件图标

### 图片节点

直接显示图片内容。

- 支持缩放和裁剪
- 从 Vault 或本地拖入图片

### URL 节点

嵌入外部链接。

- 显示网站标题和描述
- 点击打开链接

### 分组节点

将多个节点组织在一起。

- 拖拽节点到分组内
- 移动分组时内部节点跟随移动
- 支持嵌套分组

## 画布操作

| 操作 | 说明 |
|------|------|
| 滚轮缩放 | 放大/缩小视图 |
| 中键拖拽 | 平移画布 |
| 右键拖拽 | 平移画布 |
| 框选 | 按住 Shift 拖拽选择多个节点 |
| 对齐参考线 | 拖拽节点时自动显示对齐线 |

## 工具栏

白板顶部提供工具栏：

| 工具 | 说明 |
|------|------|
| 选择 | 选择和移动节点 |
| 文本 | 添加文本节点 |
| 笔记 | 添加笔记卡片 |
| 图片 | 添加图片 |
| 媒体 | 添加媒体文件 |
| URL | 添加链接节点 |
| 分组 | 创建分组 |
| 撤销/重做 | 操作历史 |

## 文件格式

白板文件使用 JSON Canvas 格式（`.canvas`），与 Obsidian 白板格式兼容：

- 跨平台兼容
- 可版本控制
- 人类可读格式

## 小窗口模式

白板可以在独立 Tauri 窗口中打开：

- 支持多显示器
- 独立操作不影响主窗口
- 窗口状态自动保存和恢复
