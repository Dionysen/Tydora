# 命令面板

命令面板让你用键盘搜索并执行 Tydora 中的几乎所有命令——从格式化文本到打开图谱、切换模式，无需在菜单里翻找。

> [!NOTE]
> 快捷键：`Ctrl+P`。

## 使用方法

1. 按 `Ctrl+P` 打开命令面板。
2. 输入命令关键词进行模糊搜索。
3. 用方向键选择，按 `Enter` 执行；或点击结果。
4. 按 `Esc` 关闭。

## 支持的命令

### 编辑命令

撤销、重做、剪切、复制、粘贴、全选等。

### 格式命令

加粗、斜体、删除线、行内代码、代码块、链接、各类标题级别、列表、任务列表等。

### 视图命令

切换编辑模式、切换侧栏、打开思维导图、打开知识图谱、打字机模式等。

### 文件命令

新建文件、保存文件、关闭文件、快速打开等。

### 模式命令

直接切换到「即时渲染」或「源码」模式。

## 搜索范围

命令面板检索所有可用命令，包括：

- 菜单中的常规命令
- 带快捷键绑定的命令
- 编辑器扩展提供的命令

> [!TIP]
> 输入中文或英文关键词都能搜到，例如「图谱」「graph」「思维」都能定位到打开知识图谱的命令。

## 最近命令

面板会记忆你最近执行过的命令并置顶，重复操作更快一步。

## 与快速打开的区别

- 命令面板（`Ctrl+P`）搜**命令**。
- 快速打开（`Ctrl+O`）搜**文件**。

> [!WARNING]
> `Ctrl+P` 在默认配置中同时绑定了「分屏预览」，但运行时命令面板优先。详见 [[07-设置/04-快捷键速查]]。
