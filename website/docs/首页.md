# Tydora

**一个现代的桌面 Markdown 编辑器**

指尖上的礼物 —— 基于 Tauri v2 + React 19 构建的沉浸式写作体验

## 核心功能

### 双模式编辑

WYSIWYG 所见即所得（TipTap 3.x）+ 源码模式（CodeMirror 6），`Ctrl+/` 随心切换，无滞于形

### 双向链接

Obsidian 风格 `<a data-note="Wiki 链接">Wiki 链接</a>`，甲篇之论可贯乙章之旨，知识互联互通

### 仓库管理

多仓库并行，文件树拖拽，井然有序。各有所属，不相混淆

### 知识图谱

可视化笔记关系网络——点若列宿，线若虹霓，万象森然

### 思维导图

Markmap 驱动，一图统览脉络分明，缩放折叠，随心所欲

### 8 款主题

Mint、Liquid Glass、Claude Code、Purple、Hermes、Next 等精选配色，昼夜咸宜。支持自定义主题和 Typora 主题导入

### 白板画布

React Flow 无限画布，拖拽组织笔记、图片、链接，对齐参考线，自由创作

### 一键发布

一键将 Vault 发布为静态网站，支持完整发布和仅公开笔记两种模式，内置预览服务器

### Callout 提示块

15 种 GitHub 风格的 Callout 块（NOTE、TIP、WARNING 等），结构化你的笔记内容

### Mermaid 图表

直接在 Markdown 中编写流程图、时序图、甘特图等，实时预览渲染
