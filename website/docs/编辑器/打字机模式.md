# 打字机模式

打字机模式（Typewriter Mode）会让**光标始终保持在屏幕垂直居中位置**。随着你不断输入，正文会向上滚动，而光标所在行稳居中央——就像老式打字机一样，让你把注意力锁定在当前这一行。

> [!NOTE]
> 快捷键：`Ctrl+Alt+T` 快速开关；也可在 [[设置/编辑器设置]] 中常开。

## 它解决什么问题

- **减少视觉疲劳**：眼睛不必在屏幕顶部与中部之间来回跳动
- **保持专注**：当前行永远居中，周围文字自然淡出视野
- **避免频繁手动滚动**：长文写作时不再需要腾出手去滚页面

## 启用方法

1. 按 `Ctrl+Alt+T` 立即切换打字机模式；或
2. 打开设置（`Ctrl+,`）→「编辑器」标签 → 开启「打字机模式」开关。

开启后，编辑器底部状态栏的打字机指示会高亮，点击它也能快速开关。

> [!TIP]
> 打字机模式与「即时渲染 / 源码」两种编辑模式都兼容，可以叠加使用。

## 使用场景

- 长文写作、随笔、日记
- 需要心流状态的专注任务
- 习惯光标居中的写作者
