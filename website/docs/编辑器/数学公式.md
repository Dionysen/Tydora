# 数学公式

Tydora 支持 **KaTeX** 与 **MathJax** 两种数学公式渲染引擎，可在行内与块级两种位置书写 LaTeX 公式。

> [!NOTE]
> 公式渲染默认开启。若不需要，可在 [[设置/编辑器设置]] 中关闭，或在 KaTeX / MathJax 之间切换引擎。

## 行内公式

用单个美元符号 `$ ... $` 包裹：

```markdown
质能方程 $E=mc^2$ 是物理学的基础。
```

显示效果：质能方程 $E=mc^2$ 是物理学的基础。

## 块级公式

用两个美元符号 `$$ ... $$` 包裹，公式会独占一行并居中：

```markdown
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

## 常用语法

### 上标与下标

```markdown
$x^2$        → 上标
$H_2O$       → 下标
$x_i^{2n}$   → 上标下标组合
```

### 分数

```markdown
$\frac{a}{b}$
```

### 根号

```markdown
$\sqrt{x}$       → 平方根
$\sqrt[n]{x}$    → n 次方根
```

### 求和、积分与连乘

```markdown
$\sum_{i=1}^{n}$   → 求和
$\int_{a}^{b}$     → 积分
$\prod_{i=1}^{n}$  → 连乘
```

### 希腊字母

```markdown
$\alpha$ $\beta$ $\gamma$ $\delta$
$\pi$ $\sigma$ $\omega$ $\theta$
```

### 矩阵

```markdown
$$
\begin{bmatrix}
1 & 2 \\
3 & 4
\end{bmatrix}
$$
```

### 多行对齐

```markdown
$$
\begin{aligned}
a &= b + c \\
  &= d + e
\end{aligned}
$$
```

## 引擎切换

在 [[设置/编辑器设置]] 的「数学公式」选项中可切换渲染引擎：

- **KaTeX** —— 渲染速度快，语法兼容性好，日常写作推荐
- **MathJax** —— 功能更全面，支持更多 LaTeX 扩展语法

> [!TIP]
> 大多数常见公式两种引擎都能正确渲染。若某条复杂公式在 KaTeX 下报错，可尝试切换到 MathJax。
