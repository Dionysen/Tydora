# 编辑模式

Tydora 支持两种编辑模式，分别对应「写得顺手」与「看得精确」两种需求。你可以在写作过程中随时切换，互不影响。

> [!NOTE]
> 按 `Ctrl+/` 可在两种模式间一键切换。也可以在设置里指定默认模式（见 [[设置/编辑器设置]]）。

## 两种模式

### 即时渲染（IR / WYSIWYG）

即时渲染模式下，你输入的 Markdown 语法会**立即变成渲染效果**，所见即所得。底层由 TipTap 3.x 引擎驱动。

**特点：**

- 标题、加粗、列表等直接以排版后的样式呈现
- 支持拖拽调整图片大小
- 原生支持 Callout 块、Mermaid 图表、代码块高亮等富元素
- 光标所在处的 Markdown 标记会按需显示，离开即隐藏
- 适合日常写作、笔记记录与快速编辑

> [!TIP]
> 即时渲染是大多数场景下的推荐模式。它的体验最接近 Typora / Obsidian 的「实时预览」。

### 源码模式（SV）

源码模式显示**纯 Markdown 文本**，由 CodeMirror 6 提供专业的语法高亮与编辑体验。

**特点：**

- 完整保留所有 Markdown 标记，便于精确控制
- CodeMirror 6 语法高亮，支持 36 种编程语言
- 代码折叠、括号匹配、自动补全
- 适合精细调整格式、批量改写、以及编辑代码块

## 如何切换

| 方式 | 操作 |
| --- | --- |
| 快捷键 | `Ctrl+/` 在 IR ↔ SV 间循环切换 |
| 快捷键（直达） | `Ctrl+Alt+7` 切到即时渲染；`Ctrl+Alt+8` 切到源码 |
| 状态栏 | 点击底部状态栏的模式指示（显示当前模式），可点击切换 |
| 设置 | 在 [[设置/编辑器设置]] 中设置默认模式 |

> [!NOTE]
> 切换模式不会改变文件内容，只是改变呈现与编辑方式。保存的始终是标准 Markdown 文本。

## 模式对比

| 特性 | IR / WYSIWYG | SV（源码） |
| --- | --- | --- |
| 格式化显示 | 立即渲染 | 显示语法标记 |
| 语法可见性 | 低（光标处局部显示） | 高 |
| 编辑体验 | 所见即所得 | 纯文本掌控 |
| 图片处理 | 可拖拽缩放 | 显示标记与路径 |
| 适合场景 | 日常写作、阅读 | 精细调整、代码编辑 |
