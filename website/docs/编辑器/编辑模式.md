# 编辑模式

Tydora 支持两种编辑模式，满足不同的编辑需求。

## 两种模式

### 即时渲染（IR / WYSIWYG）

即时渲染模式下，你输入 Markdown 语法后立即看到渲染效果，所见即所得。使用 TipTap 3.x 引擎驱动。

**特点：**

- 所见即所得，立即显示格式化效果
- 支持拖拽调整图片大小
- 丰富的扩展：Callout 块、Mermaid 图表、代码块高亮等
- 适合日常写作和快速编辑

### 源码模式（SV）

源码模式显示纯 Markdown 文本，使用 CodeMirror 6 提供专业的语法高亮和编辑体验。

**特点：**

- 显示原始 Markdown 语法
- CodeMirror 6 语法高亮
- 支持 20+ 编程语言语法高亮
- 代码折叠、括号匹配、自动补全
- 适合精细调整格式和代码编辑

## 切换模式

1. 按 `Ctrl+/` 切换编辑模式
2. 或在 [[设置/编辑器设置]] 中设置默认编辑模式

## 模式对比

| 特性       | IR / WYSIWYG | SV       |
| ---------- | ------------ | -------- |
| 格式化显示 | 立即         | 语法标记 |
| 语法可见性 | 低           | 高       |
| 编辑体验   | 所见即所得   | 纯文本   |
| 适合场景   | 日常写作     | 精细调整 |
