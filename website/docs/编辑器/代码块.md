# 代码块

Tydora 对代码提供完整的语法高亮支持，默认覆盖 **36 种编程语言**，并带有行号与一键复制。

## 创建代码块

### 方法一：Markdown 语法

使用三个反引号包裹代码，并标注语言名称以获得对应高亮：

````markdown
```javascript
function hello() {
  console.log("Hello, Tydora!");
}
```
````

> [!TIP]
> 标注语言（如 `js`、`python`、`rust`）会启用对应的语法高亮；留空则按纯文本显示。

### 方法二：快捷键

按 `Ctrl+U` 直接插入一个代码块。

### 方法三：右键菜单

1. 在编辑区右键点击。
2. 选择「插入」→「代码块」。
3. 选择编程语言。

## 支持的语言

涵盖主流语言，包括但不限于：

JavaScript、TypeScript、Python、Java、C / C++、Go、Rust、Ruby、PHP、Swift、Kotlin、SQL、HTML、CSS、Shell、JSON、YAML、Markdown 等 **36 种**。

## 行内代码

用单个反引号包裹代码片段，适用于正文中的变量名、命令等：

```markdown
使用 `console.log()` 输出日志
```

> 快捷键：`Ctrl+E`。

## 行号

代码块默认显示行号，便于对照与引用。可在 [[设置/编辑器设置]] 中关闭。

## 复制代码

将鼠标移到代码块右上角，点击出现的**复制**按钮即可将代码内容复制到剪贴板。

## 代码高亮主题

代码块的配色独立于应用主题，可在 [[设置/编辑器设置]] 中切换，共有 11 款高亮主题：

- 浅色：Atom One Light、GitHub Light、VS Code Light、Solarized Light
- 深色：Atom One Dark、GitHub Dark、VS Code Dark、Nord、Monokai、Dracula、Solarized Dark

> 也可跟随应用外观自动在浅 / 深高亮主题间切换。详见 [[代码高亮主题]]。
