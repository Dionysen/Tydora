# 快速打开

「快速打开」让你用键盘瞬间定位并打开仓库中的任意文件，是摆脱鼠标、提升导航效率的核心功能。

> [!NOTE]
> 快捷键：`Ctrl+O`。

## 使用方法

1. 按 `Ctrl+O` 打开快速打面板。
2. 输入文件名关键词进行**模糊搜索**。
3. 用上下方向键选择结果，按 `Enter` 打开；或直接点击结果。
4. 按 `Esc` 关闭面板。

## 模糊搜索

快速打开支持模糊匹配，无需输入完整文件名：

- 输入 `笔记` → 匹配 `我的笔记.md`、`笔记管理.md`
- 输入 `2024日` → 匹配 `2024年日记.md`
- 输入 `项目 readme` → 匹配 `项目/README.md`（跨层级也可匹配）

> [!TIP]
> 搜索范围是**当前活跃仓库**内的全部文件。要搜其他仓库，先切换仓库（见 [[文件管理/仓库]]）。

## 最近文件

面板打开时会显示**最近打开的文件**列表，常用文件一触即达，不必每次都搜索。

## 与命令面板的关系

- **快速打开**（`Ctrl+O`）只搜「文件」。
- **命令面板**（`Ctrl+P`）只搜「命令」。

两者配合，几乎可以纯键盘完成所有操作。
