# 知识图谱

知识图谱用可视化方式呈现笔记之间的链接关系，帮你从「单篇笔记」跃升到「知识网络」的视角，发现结构、核心与孤岛。

> [!NOTE]
> 快捷键：`Ctrl+G`。图谱基于 D3.js 力导向图渲染，可在独立窗口或主区打开（见下方「打开方式」）。

## 功能说明

- 基于 D3.js **力导向图**：节点彼此吸引 / 排斥，自动聚拢成簇
- **节点大小**反映链接数量（被引用越多越大）
- **连线粗细**反映链接频率
- 支持缩放、拖拽、点击跳转

## 打开方式

按 `Ctrl+G` 打开图谱。其行为由设置决定：

- 若开启「在新窗口打开」（[[设置/思维导图设置]] 中的图谱设置），则在独立 Tauri 窗口中显示，支持多显示器
- 否则在主区域以面板形式显示

## 图谱解读

### 节点

- 圆形大小表示该笔记的链接数量
- 被引用越多的笔记，节点越大，越可能是「核心笔记」
- 颜色可表示笔记的分组（如按文件夹）

### 连线

- 表示笔记间的 [[Wiki链接]] 关系
- 连线粗细表示链接出现频率
- 箭头方向表示引用方向（A → B 表示 A 引用了 B）

### 布局

- 力导向图会自动寻找平衡布局
- 关联密集的笔记聚成一簇
- 孤立（无链接）的笔记散落在边缘

## 使用方法

1. 按 `Ctrl+G` 打开知识图谱。
2. 在窗口中查看笔记关系网络。
3. **点击节点**打开对应笔记。
4. 用**鼠标滚轮**缩放，**拖拽节点**调整布局。
5. 悬停节点可显示标题。

## 使用场景

- 俯瞰知识网络的**整体结构**
- 找出**核心笔记**（节点最大的那些）
- 发现**孤立笔记**（没有连线的），回头补链
- 理解知识体系的脉络与聚类
