# 反向链接

反向链接（Backlinks）面板显示**有哪些笔记链接到了当前笔记**。它把「我引用了谁」反转成「谁引用了我」，是发现笔记间隐藏关联的关键视图。

> [!NOTE]
> 在左侧边栏切换到「反向链接」标签即可查看。它依赖 [[03-知识管理/05-链接索引]] 后台服务实时维护。

## 功能说明

- **实时更新**：新增 / 删除链接后，反向链接即时刷新
- **上下文片段**：不仅显示来源笔记，还展示链接出现的上下文句子
- **一键跳转**：点击任意条目，直接打开来源笔记并定位

## 使用方法

1. 打开任意一篇笔记。
2. 在左侧边栏顶部切换到「反向链接」标签。
3. 查看引用了当前笔记的所有来源列表。
4. 点击条目跳转回来源笔记。

## 使用场景

- **发现隐藏关联**：你可能忘了某篇笔记引用了当前内容，反向链接帮你找回
- **回顾引用**：梳理「哪些内容在支撑当前观点」
- **评估重要性**：被引用越多的笔记往往越核心
- **排查断链 / 孤立笔记**：没有反向链接的笔记可能是「信息孤岛」，值得回顾补链

> [!TIP]
> 配合 [[03-知识管理/04-知识图谱]] 使用效果更佳：反向链接看「线性列表」，图谱看「网状结构」。

## 链接索引

反向链接由 [[03-知识管理/05-链接索引]] 服务提供数据支撑。Inimark 在后台自动构建并维护链接关系，无需手动刷新。
