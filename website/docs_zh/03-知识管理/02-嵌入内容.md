# 嵌入内容

嵌入（Embed）让你把**其他笔记或媒体**的内容直接显示在当前的笔记中，而不是只放一个跳转链接。常用于复用模板、聚合资料、集中管理图片。

> [!NOTE]
> 语法是在 Wiki 链接前加 `!`：`![[笔记名]]`。

## 基本语法

```markdown
![[笔记名]]
```

当前笔记会**内联渲染**「笔记名」的全部内容。

## 嵌入标题

只嵌入目标笔记中的某个标题及其下属内容：

```markdown
![[笔记名#标题]]
```

适合把长篇笔记里的某一节抽出来复用。

## 嵌入图片

```markdown
![[图片路径.png]]
```

仓库中的图片会直接显示在当前位置（也支持 `![alt](路径)` 标准语法）。

## 嵌入视频 / 音频

```markdown
![[视频路径.mp4]]
![[音频路径.mp3]]
```

仓库中的视频、音频文件会以内嵌播放器形式呈现。

## 使用场景

- **引用段落**：把常用说明、定义从「母笔记」嵌入多处，改一处全局更新
- **集中管理图片**：图片统一放在 `assets` 类文件夹，正文用嵌入引用
- **内容聚合页**：用嵌入把多篇笔记汇成「日报 / 周报 / 索引页」
- **复用模板**：把模板笔记嵌入新笔记，快速套用结构

> [!TIP]
> 嵌入与 [[03-知识管理/01-Wiki链接]] 搭配使用：用 `[[笔记]]` 跳转，用 `![[笔记]]` 内联，按需选择。

## 注意事项

- 嵌入的内容为**只读**，不能在当前笔记里直接编辑
- 修改源笔记，会**同步反映**到所有嵌入它的地方
- 支持嵌入图片、视频、音频等多媒体文件
- 深层嵌套嵌入（A 嵌入 B，B 嵌入 C）也能正常展开
