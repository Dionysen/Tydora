# Wiki 链接

Wiki 链接是 Inimark 知识管理的核心：用 `[[笔记名]]` 就能在笔记之间建立**双向链接**，把零散的笔记织成网络。语法与 Obsidian 一致。

> [!NOTE]
> 输入 `[[` 即触发自动补全，输入关键词即可筛选目标笔记。链接解析依赖 [[03-知识管理/05-链接索引]]。

## 基本语法

### 链接到笔记

```markdown
[[笔记名]]
```

渲染为可点击的链接，点击后跳转到对应笔记。

### 带别名的链接

```markdown
[[笔记名|显示文本]]
```

显示「显示文本」，但指向「笔记名」。适合在句中自然引用。

### 链接到标题

```markdown
[[笔记名#标题]]
```

直接跳转到目标笔记中的指定标题位置。

## 使用方法

1. 在编辑器中输入 `[[`。
2. 继续输入笔记名（支持模糊匹配）。
3. 从自动补全列表中选择目标。
4. 按 `Enter` 确认，链接插入完成。

> [!TIP]
> 候选列表会显示匹配的文件路径，重名笔记也能准确区分。

## 自动补全

输入 `[[` 后，Inimark 会弹出匹配笔记列表：

- 支持**模糊搜索**：输入部分关键词即可过滤
- 实时更新：边输入边筛选
- 键盘操作：`↑` / `↓` 选择，`Enter` 确认，`Esc` 关闭

## 链接到不存在的笔记

如果链接指向的笔记尚不存在，点击该链接会**自动创建**新笔记，并打开它。这让「先链接、后补全」的写作流非常顺滑。

## 嵌入内容

在 `[[` 前加 `!` 可嵌入（而非跳转）其他笔记内容：

```markdown
![[笔记名]]
```

> 详见 [[03-知识管理/02-嵌入内容]]。

## 反向链接

当别的笔记链接到当前笔记时，[[03-知识管理/03-反向链接]] 面板会列出所有来源，帮你发现「谁引用了我」。
