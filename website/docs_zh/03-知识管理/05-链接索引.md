# 链接索引

链接索引是 Inimark 的**后台服务**，负责扫描仓库、构建并维护所有笔记之间的链接关系。它是 [[03-知识管理/01-Wiki链接]] 自动补全、[[03-知识管理/03-反向链接]] 面板、[[03-知识管理/04-知识图谱]] 与 [[05-导航与搜索/01-快速打开]] 的数据底座。

> [!ABSTRACT]
> 你通常无需直接接触链接索引——它在后台静默工作。本页说明它的机制，便于理解为何链接「总能正确解析」。

## 功能说明

- 自动扫描仓库中的全部笔记
- 构建**出链（outlinks）**索引：当前笔记链接了哪些笔记
- 构建**反链（backlinks）**索引：哪些笔记链接了当前笔记
- 构建**文件名索引**：文件名到路径的映射（支撑 `[[笔记名]]` 解析与补全）
- 支持**增量更新**，不重复全量扫描

## 工作机制

### 索引构建

1. 启动时扫描整个仓库
2. 解析所有 Markdown 文件中的 `[[03-知识管理/01-Wiki链接]]` 与 `![[嵌入]]`
3. 构建双向链接关系表

### 增量更新

- 监听文件系统变化（新增 / 删除 / 重命名 / 修改）
- 仅更新受影响文件的链接关系
- 文件重命名时，尝试更新指向它的链接，保持不失效

### 索引内容

| 索引类型 | 说明 |
| --- | --- |
| 出链 | 当前笔记链接了哪些笔记 |
| 反链 | 哪些笔记链接了当前笔记 |
| 文件名 | 文件名 → 路径映射，支撑解析与补全 |

## 性能优化

- **批量处理**：每次最多处理 50 个文件，避免一次性占用主线程
- **后台异步**：索引构建在后台进行，不阻塞编辑
- **增量优先**：日常编辑只触发小范围更新

> [!TIP]
> 仓库很大时，首次启动的索引构建可能稍耗时，之后都会是轻量的增量更新。
