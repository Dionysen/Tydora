# 快捷键设置

Tydora 内置 **40+ 个可自定义**的键盘快捷键。你可以在设置中查看全部绑定、修改为习惯的组合，或一键恢复默认。

> [!NOTE]
> 按 `Ctrl+,` 打开设置，切换到「快捷键」标签。完整默认列表见 [[07-设置/04-快捷键速查]]。

## 快捷键分组

设置中的快捷键按功能分组，便于查找：

### 格式

加粗、斜体、删除线、行内代码、代码块、链接、高亮、引用、水平分割线等。

### 列表

无序列表、有序列表、任务列表、增加 / 减少缩进、切换任务状态。

### 标题

1–6 级标题切换、段落。

### 插入

表格、在上方 / 下方插入。

### 表格

插入行 / 列、删除行 / 列、单元格对齐。

### 编辑

撤销、重做、全选（代码块内）。

### 视图

切换侧栏、全屏、打字机模式、打开思维导图。

### 模式

切到即时渲染、切到源码。

### 系统

快速打开、命令面板、关闭提示。

## 自定义快捷键

1. 在快捷键列表中找到目标命令。
2. 点击当前的快捷键组合。
3. 按下新的组合键。
4. 自动保存，立即生效。

> [!TIP]
> 修改后无需重启。若新组合与已有快捷键冲突，系统会提示你确认（见下）。

## 重置快捷键

点击「重置」按钮，可将**所有**快捷键恢复为默认值。单条命令也可单独重置（通常在编辑该项时提供「恢复默认」）。

## 冲突检测

如果新设置的快捷键与现有绑定冲突，系统会提示确认，避免无声覆盖导致命令失效。

> [!WARNING]
> 默认配置中 `Ctrl+O` 被两个命令共用（快速打开 / 有序列表），运行时以全局命令为准。若你重新分配了相关命令，请留意实际行为。详见 [[07-设置/04-快捷键速查]]。
