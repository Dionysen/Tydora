# 思维导图

Inimark 内置思维导图功能，基于 **Markmap** 将 Markdown 的标题层级自动转换为可交互的思维导图，帮你从「线性文字」切换到「树状结构」来审视内容。

> [!NOTE]
> 快捷键：`Ctrl+M`。思维导图在独立 Tauri 窗口中打开，支持多显示器。

## 使用方法

1. 按 `Ctrl+M` 打开思维导图。
2. 在独立窗口中查看当前笔记（或文档）生成的思维导图。
3. 用鼠标滚轮缩放，拖拽画布平移。
4. 点击节点可折叠 / 展开其子节点。

> [!TIP]
> 思维导图内容取自当前正在编辑的文档；保存后再打开，会反映最新结构。

## 功能特性

### 缩放与平移

- **滚轮缩放**：放大 / 缩小
- **拖拽平移**：按住空白处拖动调整视图
- **双击居中**：双击节点将其居中显示

### 折叠与展开

- 点击节点**折叠**其下级分支
- 点击已折叠节点**展开**
- 支持一次性全部折叠 / 展开（窗口内提供控件）

### 缩放级别设置

在 [[07-设置/05-思维导图设置]] 中可调：

- 默认展开层级
- 动画时长
- 节点间距
- 连接线宽度
- 颜色冻结层级（从第几层起用不同颜色区分深度）

## Markdown 格式

思维导图完全由标题层级生成，无需额外标记：

```markdown
# 根节点
## 一级节点 1
### 二级节点 1.1
### 二级节点 1.2
## 一级节点 2
### 二级节点 2.1
```

- 一级标题 `#` 作为根
- 二级 `##` 作为第一层分支，依此类推
- 列表、正文不进入导图，只有标题参与

## 使用场景

- **大纲可视化**：写长篇前先列标题，导图一眼看清结构
- **创意发散**：用标题层级做头脑风暴的骨架
- **项目规划**：把目标 → 阶段 → 任务逐层展开
- **知识整理**：把一篇读书笔记的章节变成知识地图
