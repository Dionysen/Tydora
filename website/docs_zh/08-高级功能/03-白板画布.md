# 白板画布

白板画布（Canvas）基于 **React Flow** 构建，提供一个**无限画布**，让你用节点自由组织想法、笔记、图片、媒体与链接——像在纸上铺开，却可无限延展、随手连线。

> [!NOTE]
> 白板文件以 `.canvas` 扩展名保存，采用与 Obsidian 兼容的 JSON Canvas 格式。

## 打开白板

1. 在文件树中右键，选择「新建白板」；或
2. 在命令面板（`Ctrl+P`）中搜索「白板」并创建；或
3. 打开已有的 `.canvas` 文件。

白板会在主区域打开，像普通笔记一样参与文件树与最近文件管理。

## 节点类型

白板支持多种节点，覆盖不同的组织需求：

### 文本节点

自由编辑的文本块，使用 TipTap 编辑器即时渲染。

- 支持 Markdown 语法
- 可任意拖拽、调整大小
- 适合标注、说明与即兴记录

### 笔记卡片

引用 Vault 中的 Markdown 文件。

- 显示笔记标题与摘要
- 点击跳转到笔记原文
- 与 `[[03-知识管理/01-Wiki链接]]` 体系互通

### 文件引用

引用图片、视频、音频、PDF 等媒体文件。

- 图片直接显示缩略图
- 视频 / 音频显示播放图标
- PDF 显示文件图标

### 图片节点

直接显示图片内容。

- 支持缩放与裁剪
- 可从 Vault 或本地拖入图片

### URL 节点

嵌入外部链接。

- 显示网站标题与描述
- 点击在浏览器打开链接

### 分组节点

把多个节点归为一组。

- 拖拽节点进分组即可加入
- 移动分组时内部节点跟随移动
- 支持嵌套分组，构建层级

## 画布操作

| 操作 | 说明 |
| --- | --- |
| 滚轮缩放 | 放大 / 缩小视图 |
| 中键拖拽 | 平移画布 |
| 右键拖拽 | 平移画布 |
| 框选 | 按住拖拽选择多个节点（配合 `Shift` 可加选） |
| 对齐参考线 | 拖拽节点时自动出现对齐线，便于整齐排布 |

## 工具栏

白板顶部工具栏提供：

| 工具 | 说明 |
| --- | --- |
| 选择 | 选择与移动节点 |
| 文本 | 添加文本节点 |
| 笔记 | 添加笔记卡片 |
| 图片 | 添加图片 |
| 媒体 | 添加媒体文件 |
| URL | 添加链接节点 |
| 分组 | 创建分组 |
| 撤销 / 重做 | 操作历史 |

## 文件格式

白板使用 **JSON Canvas** 格式（`.canvas`），与 Obsidian 白板格式兼容：

- **跨平台兼容**：可在支持该格式的工具间互通
- **可版本控制**：纯文本 JSON，适合纳入 Git
- **人类可读**：可直接查看与手工编辑

## 小窗口模式

白板可在独立 Tauri 窗口中打开：

- 支持多显示器，把白板放在副屏
- 独立操作不影响主窗口编辑
- 窗口位置与大小自动保存恢复

> [!TIP]
- 用「笔记卡片」把白板与你的知识库连起来：白板负责发散与布局，笔记负责沉淀细节，二者互相引用。
