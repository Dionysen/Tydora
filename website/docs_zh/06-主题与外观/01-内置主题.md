# 内置主题

Inimark 提供 **9 款**精心设计的内置主题，覆盖清新、沉稳、活力、未来感等多种风格，并均支持浅色 / 深色外观。你可以在设置中一键切换，也可以导入自己的 CSS 主题（见 [[06-主题与外观/02-Typora主题]]）。

> [!NOTE]
> 默认主题为 **Mint**。代码块的配色可独立于应用主题设置，详见 [[06-主题与外观/03-代码高亮主题]]。

## 主题列表

### 白色（White）

简洁纯净的白色背景，适合长时间阅读与日常写作的通用浅色主题。

### Mint *（默认）*

清新的薄荷绿主题，以白色为底、薄荷绿为强调色，自然舒缓。**这是 Inimark 的默认主题。**

### Mint Dark

Mint 的深色版本，深色背景下保留薄荷绿强调色，适合偏好暗色环境又喜欢绿色调的用户。

### Claude Code

灵感来自 Claude 代码编辑器的暖色调深色主题，米白底搭配琥珀色强调，温润而专注。

### Purple

优雅的紫色主题，柔和紫调适合喜欢浪漫、静谧氛围的用户。

### Hermes

充满活力的蓝色 / 靛蓝主题，强调色鲜明，现代感强。

### NexT

未来感主题，灵感来自 Hexo NexT Pisces 风格，青绿强调色搭配米白底，精致克制。

### Slate

石墨灰简约主题，低饱和冷灰配色，沉稳专业，适合严肃写作与文档场景。

### Ocean

海洋冷色调主题，浅蓝背景搭配青色强调，清爽通透。

## 切换主题

### 方法一：设置面板

1. 打开设置（`Ctrl+,`）。
2. 切换到「主题」标签。
3. 在主题列表中点击选择，立即生效。

### 方法二：仓库切换器

1. 点击侧栏底部的仓库切换器。
2. 点击设置（齿轮）图标。
3. 在弹出菜单中选择主题。

## 外观模式

每款主题都可配合三种外观模式使用：

- **跟随系统** —— 自动跟随操作系统的浅色 / 深色设置切换
- **浅色** —— 强制浅色渲染
- **深色** —— 强制深色渲染

> 外观模式在 [[07-设置/01-通用设置]] 中设置。Mint Dark 等深色主题在「深色」模式下观感最佳。
