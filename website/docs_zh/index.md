# Inimark 帮助文档

> **语言：** **中文** | [English](en/)

欢迎来到 **Inimark 帮助文档**。

**Inimark** — 无限书写，思维无界。它是一张小而美的书桌：专注编辑，也帮你把想法连起来、看清楚。本地优先，界面克制，不多一分打扰。

## 新手上路

建议按下面的顺序阅读，大约 10 分钟即可上手：

1. [[01-开始使用/01-快速开始]] —— 下载安装、打开仓库、写下第一篇笔记
2. [[02-编辑器/01-编辑模式]] —— 即时渲染与源码模式，随时切换
3. [[02-编辑器/02-Markdown语法]] —— Inimark 支持的 Markdown 与扩展语法
4. [[03-知识管理/01-Wiki链接]] —— 用双向链接把想法连起来
5. [[03-知识管理/04-知识图谱]] —— 从全局视角看笔记关系
6. [[08-高级功能/02-思维导图]] —— 把文档展开为思维导图
7. [[08-高级功能/03-白板画布]] —— 在无限画布上整理思路
