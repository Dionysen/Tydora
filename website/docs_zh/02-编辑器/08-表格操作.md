# 表格操作

Inimark 提供便捷的表格编辑能力：既可以用标准 Markdown 语法书写，也可以在即时渲染模式下通过浮动工具栏可视化增删行列、调整对齐。

> [!NOTE]
> 插入表格快捷键：Ctrl+T。在即时渲染模式下，把光标放入表格会出现浮动工具栏。

## 创建表格

### 方法一：Markdown 语法

```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容 | 内容 | 内容 |
```

### 方法二：快捷键

按 `Ctrl+T` 插入一个默认大小的表格。

### 方法三：右键菜单

1. 在编辑区右键点击。
2. 选择「插入」→「表格」。
3. 在弹出的网格选择器中拖动选择行数与列数，点击确认。

## 编辑表格

### 在即时渲染模式下

- 把光标放入表格，上方会浮现**表格浮动工具栏**，可：插入行 / 列、删除表格、调整大小。
- 直接在单元格内输入文字，Tab 键移动到下一格。

### 增删行列

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 在上方插入行 | `Ctrl+Shift+F` | — |
| 在下方插入行 | `Ctrl+Shift+.` | — |
| 在左侧插入列 | `Ctrl+Shift+G` | — |
| 在右侧插入列 | `Ctrl+Shift+=` | — |
| 删除行 | `Ctrl+-` | — |
| 删除列 | `Ctrl+Shift+-` | 右键也可删除 |

### 单元格对齐

在 Markdown 分隔行中用冒号设置对齐方式：

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:-------:|-------:|
| 内容   | 内容    | 内容   |
```

快捷键：

| 对齐方式 | 快捷键 |
| --- | --- |
| 左对齐 | `Ctrl+Shift+L` |
| 居中对齐 | `Ctrl+Shift+C` |
| 右对齐 | `Ctrl+Shift+R` |

## 在源码模式下调整

源码模式下直接编辑管道符表格即可；Inimark 会在你输入时保持列对齐，方便阅读。

> [!TIP]列数较多时，建议先在即时渲染模式下用浮动工具栏增列，再用快捷键批量对齐，效率更高。
