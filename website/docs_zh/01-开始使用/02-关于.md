# 关于 Inimark

**Inimark** — 无限书写，思维无界。

它是一张安静的书桌：基于 Tauri v2 + React 19 构建，本地优先，开源免费。书写可以没有尽头，思维也不必画地为牢；我们把它做得足够小、足够美，刚好容纳你不断延伸的想法。

## 产品理念

Inimark 不做功能大全，只做两件事：

- **专注编辑**：所见即所得与源码随切随用，界面克制。工具退到幕后，字先写好。
- **专注思维**：双向链接、知识图谱、思维导图、白板——在需要时帮你看清脉络，而不是另建一套臃肿系统。

所有笔记与文件都在你的本地文件夹里。不收集个人数据，也不依赖云端。

> [!NOTE]
> Inimark 采用 Apache License 2.0 开源。欢迎在 GitHub 提 Issue、参与讨论或贡献代码。

## 检查更新

Inimark 支持自动更新：启动时会在后台检查新版本，若有则提示下载安装。

手动检查：

1. 打开设置（`Ctrl+,`）
2. 切换到「关于」
3. 点击「检查更新」

> [!TIP]
> 自动更新依赖 GitHub Releases 上的签名文件。配置详见 [[09-blog/自动更新配置]]（面向贡献者）。

## 功能一览

**编辑**

- 即时渲染（IR）与源码（SV）双模式，`Ctrl+/` 切换
- 打字机模式、Frontmatter 属性面板
- 代码块、数学公式、Mermaid、Callout、表格

**思维**

- WikiLink 双向链接与反向链接
- 知识图谱（D3.js 力导向图）
- 思维导图（从 Markdown 标题 / 列表生成）
- 白板画布（JSON Canvas 格式）

**基础**

- 多仓库、文件树拖拽、多媒体预览
- 内置主题与代码高亮、可定制快捷键
- 快速打开、命令面板、大纲面板
