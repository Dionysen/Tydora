# 快速开始

无限书写，思维无界。本页带你从安装到写下第一篇笔记，约 5 分钟上手。

> [!NOTE]
> Inimark 用「仓库（Vault）」管理本地文件夹里的笔记。所有文件都在你的磁盘上，不经过任何云端。

## 一、安装

打开 [GitHub Releases](https://github.com/Dionysen/Inimark/releases) 页面。

1. 根据系统下载安装包：
   - **Windows**：`Inimark_x.x.x_x64-setup.exe`
   - **macOS**：`Inimark_aarch64.app.tar.gz`（Apple 芯片）或 `Inimark_x64.app.tar.gz`（Intel）
   - **Linux**：`Inimark_amd64.AppImage`
2. 运行安装程序，按提示完成。
3. 启动 Inimark。

> [!TIP]
> 首次启动后会自动检查更新。也可在设置 → 关于中手动检查。

## 二、打开仓库

1. 点击左侧边栏底部的**仓库切换器**。
2. 选择「添加仓库」。
3. 挑选一个本地文件夹（可新建空文件夹）。
4. 确认后，左侧显示该文件夹的**文件树**。

> [!ABSTRACT]
> 仓库只记录文件夹路径，不会移动或复制你的文件。可添加多个仓库，按项目分别管理。详见 [[04-文件管理/01-仓库]]。

## 三、创建第一篇笔记

1. 在**文件树**中右键目标文件夹。
2. 选择「新建文件」。
3. 输入文件名，如 `我的第一篇笔记`（`.md` 后缀可省略）。
4. 按 `Enter`，编辑器打开该文件。
5. 开始写作。

## 四、基本编辑

Inimark 提供两种编辑模式：

- **即时渲染（IR）**：所见即所得，适合日常写作。
- **源码模式（SV）**：纯 Markdown 文本，适合精细调整格式。

按 `Ctrl+/` 随时切换。详见 [[02-编辑器/01-编辑模式]]。

> [!TIP]
> 需要专注时，可在设置中开启**打字机模式**，光标始终居中。

## 五、保存文件

- 手动保存：`Ctrl+S`
- 自动保存：在 [[07-设置/01-通用设置]] 中开启，停止输入约 1 秒后自动写入

> [!WARNING]
> 删除文件不可撤销，重要笔记请做好备份。

## 七、下一步

写好第一篇笔记后，可以逐步探索：

1. **继续写** — 熟悉 [[02-编辑器/02-Markdown语法]] 与 [[02-编辑器/10-打字机模式]]
2. **连起来** — 用 `[[另一篇笔记]]` 建立链接 → [[03-知识管理/01-Wiki链接]]
3. **看结构** — 按 `Ctrl+G` 打开知识图谱，或 `Ctrl+M` 生成思维导图
4. **铺开来** — 在 [[08-高级功能/03-白板画布]] 上整理复杂思路
