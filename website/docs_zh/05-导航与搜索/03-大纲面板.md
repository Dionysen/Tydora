# 大纲面板

大纲面板显示**当前文档的标题结构**，让你一眼看清文章骨架，并随手跳转到任意章节。

> [!NOTE]
> 切换到左侧边栏的「大纲」标签即可查看。它与「文件」「反向链接」等标签并列。

## 功能说明

- 自动解析 Markdown 标题（1–6 级）
- 按标题层级**缩进展示**，结构一目了然
- 点击任意标题，编辑器滚动到对应位置
- 高亮显示**当前阅读位置**（随滚动同步）

## 使用方法

1. 在左侧边栏顶部切换到「大纲」标签。
2. 查看当前文档的标题列表（含层级）。
3. 点击某个标题，正文立即滚动定位过去。

## 标题层级

大纲支持全部 6 级标题：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 使用场景

- **长文档导航**：动辄数千字时，靠大纲比滚动高效得多
- **查看结构**：写作前先列大纲，写作中随时核对章节完整性
- **跳转章节**：点击即达，不必手动翻找

> [!TIP]
> 大纲与 [[03-知识管理/04-知识图谱]] 互补：大纲看「单篇结构」，图谱看「笔记之间的关系」。
