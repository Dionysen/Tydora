Let Your Ideas Flow

Tydora is a modern desktop Markdown editor combining WYSIWYG editing, bidirectional links, mind maps, and an infinite canvas — empowering deep thinking and effortless expression.

Everything You Need

From editing and linking to visualization and publishing — all in one app.

✏️

Dual-Mode Editing

Seamlessly switch between WYSIWYG (TipTap) and Source Mode (CodeMirror 6). See what you get, or get your hands dirty with raw Markdown.

🔗

Bidirectional Links

Obsidian-flavored [[wikilinks]] with backlink panels, auto-completion, hover previews, and real-time reference tracking.

🗺️

Knowledge Graph

D3-powered force-directed graph visualizing how your notes connect. Click any node to navigate instantly.

🧠

Mind Map

Auto-generated interactive mind maps from your Markdown headings. Pan, zoom, and explore your document structure visually.

🎨

Infinite Canvas

A freeform whiteboard canvas. Drop text cards, notes, media, URLs — arrange ideas spatially beyond linear documents.

🎭

Rich Theming

8 built-in themes + custom CSS import + 11 syntax-highlight color schemes. Make it truly yours.

📤

One-Click Publish

Turn your vault into a static website in one click. Built-in preview server — share your knowledge with the world.

🪟

Multi-Window

Settings, graph, mind map, and canvas each open in independent windows. Perfect for multi-monitor workflows.

A force-directed graph rendering every note as a node and every link as an edge. Filter by depth, highlight connections, and jump to any note with a click.

D3 Force Layout Interactive Depth Filter

Mind Map

Automatically generated from your document's heading hierarchy. Zoom, pan, collapse branches — visual navigation for long-form writing.
